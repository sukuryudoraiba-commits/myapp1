# カードクローゼット

手持ちのカードを記録・整理するコレクション管理アプリ（PWA プロトタイプ）。
非公式のファンメイドツールで、公式のカード画像・ロゴは含みません。

## 機能
| 画面 | できること |
| --- | --- |
| ホーム | 所持種類・総枚数・ダブり・欲しい数のサマリ、弾ごとのコンプ率バー |
| カード | 一覧表示、検索（名前/ブランド/No.）、弾・所持状況・レアリティ・部位での絞り込み、＋/−で枚数変更 |
| 欲しい | 欲しいものリスト、「ゲット！」で所持に変更、テキストでコピー |
| ダブり | 2枚以上あるカードと余り枚数、交換用リストをテキストでコピー |
| 設定 | JSONでバックアップ／復元、全データ削除 |

カード登録では写真（自分で撮影）、カード名、弾、No.、レアリティ、部位、ブランド、枚数、欲しいフラグ、メモを記録できます。

## データ
すべて端末内の IndexedDB に保存されます（サーバー不要・外部送信なし）。写真は 520px に縮小して保存。

## 起動方法
ビルド不要の静的ファイルです。
```sh
python3 -m http.server 8000
# → http://localhost:8000 を開く
```
GitHub Pages などに置けばスマホから「ホーム画面に追加」でアプリとして使えます。
